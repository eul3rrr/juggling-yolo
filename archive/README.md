# Research archive

These experiments informed the project but are not the implementation behind the frozen README demo. They include failed approaches, intermediate outputs, and research notes. Their conclusions apply to their original datasets and settings, not automatically to the current hand-repair subsystem.

Start with the [project README](../README.md) for the demonstrated pipeline.

## Browse the history

- [Results log](overnight/RESULTS_LOG.md): experiments, findings, and negative results.
- [Reports](overnight/reports/): ballistic fitting, assignment, hand heuristics, and detector investigations.
- [Scripts](overnight/scripts/): original experiment implementations.
- [Data](overnight/data/): saved intermediate results and literature-search material.
- [Earlier runnable baseline commands](../docs/BASELINES.md): detection, tracking, and manual stitch review.

## Preservation policy

`overnight/` was moved from `experiments/overnight/` without changing its tracked contents. The old location and development-machine paths may still appear inside historical reports and shell scripts. This is an archive, not the supported demo command path; do not run the old shell scripts expecting a portable setup.

The original layout remains available at [commit 933abfb6648af4fd25cb8cfcee1c9c75284ab0c9](https://github.com/eul3rrr/juggling-yolo/tree/933abfb6648af4fd25cb8cfcee1c9c75284ab0c9/experiments/overnight). Research branches are retained. No experiment results were deleted or reinterpreted during the presentation cleanup.
